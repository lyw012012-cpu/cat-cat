# 🐱 집사 고양이

PC에 사는 고양이가 유튜브 쇼츠·릴스 같은 업무 방해 요소를 감지해 막아주는 생산성 앱. (v0.1 개발 중)

## 무엇을 기록하나 (개인정보)
- 지금 보고 있는 **앱 이름**, **창 제목**, 브라우저의 **전체 주소**(예: `youtube.com/shorts/…`), 사용 시간
- 고양이가 감지·차단한 기록 (그때 모드, 실제로 닫았는지)
- 1초 이하로 스쳐 간 창은 저장하지 않는다
- 상세 기록은 **90일** 뒤 자동 삭제. 하루 요약(앱·사이트별 사용 시간)과 고양이의 채찍·당근 기억은 계속 남는다
- 기록은 **이 PC에만** 저장된다: `%LOCALAPPDATA%\cat-app\cat.db`
- 인터넷으로 아무것도 보내지 않는다. 기록을 지우려면 위 파일을 삭제하면 된다.

## 설치 (Windows, Python 3.10+)
```powershell
git clone <이 저장소 주소>
cd <폴더>
pip install -r requirements.txt   # uiautomation(브라우저 주소 읽기), pycaw(크롬 소리 끄기)
```

## 실행
```powershell
python cat_app.py --simulate      # 가짜 시나리오로 동작 확인 (아무 OS)
python cat_app.py                 # 고양이 창이 뜨고 감시 모드로 시작
python cat_app.py 업무모드         # 업무모드로 시작
```
켜져 있는 동안 고양이 창에서 **감시 모드 ↔ 업무모드**를 언제든 바꿀 수 있다. 창을 닫으면 종료되고 오늘 통계가 터미널에 나온다.

### 고양이 반응 단계
🗣️ 말하기 → 🔇 소리 끄기(크롬) → 🚪 10초 기다리게 → 🐾 탭 닫기

| | 쇼츠·릴스·틱톡 | 유튜브 딴짓 영상 (아래 '영상 종류' 참고) |
|---|---|---|
| 업무모드 | **첫 번째부터 바로 탭 닫기** | 오늘 누적 **5분마다 한 단계씩**: 5분 말하기 → 10분 소리 끄기 → 15분 기다리게 → 20분부터 닫기 |
| 감시 모드 | 말하기만. 오늘 누적 1시간 넘으면 소리 끄기까지 | 같음 |

- 단계는 한 번에 한 칸씩만 오른다 (이미 여러 번 본 뒤라도 첫 반응은 말하기).
- 고양이는 다음에 할 일을 말로 예고한다: "딴짓 5분째야. 5분 더 보면 소리 안 들리게 할 거야." / "또 쇼츠야? 꺼 버렸어. 업무 중엔 쇼츠 금지야."

소리는 규칙에 걸리지 않는 창(강의, 다른 앱)으로 옮기거나 앱을 끄면 다시 켜진다.

### 유튜브 영상 종류 (자동 분류)
영상마다 YouTube가 가진 **카테고리**를 한 번 읽어서(API 키 불필요, 영상당 한 번, 결과 저장) 나눈다.

| YouTube 카테고리 | 판정 |
|---|---|
| Music | 🎵 노래 → 집중 |
| Education · Science & Technology · Howto & Style | 📚 강의 → 집중 |
| Gaming · Comedy · Sports · Pets & Animals 등 | 😼 딴짓 영상 → 단계 반응 |
| Entertainment · People & Blogs · Film · News 등, 또는 못 읽음 | 🤔 애매 → 업무모드에서 10초 보면 **"이거 강의 맞아?"** (감시 모드는 묻지 않고 딴짓으로 봄) |

- 카테고리는 업로더가 고른 값이라 틀릴 수 있다 (예: 노래인데 People & Blogs). 그래서 애매하면 묻고, 대답은 영상별로 기억한다.
- 제목에 강의·노래 단어(강의, 파이썬, lofi …)가 있으면 애매한 카테고리여도 강의로 본다.

### 업무모드: 자동 분류 (인터넷 전체)
할 일을 따로 고르지 않는다. 고양이가 창을 보고 스스로 나눈다. 위에서부터 먼저 걸리는 것:

| 순서 | 판정 근거 | 예 |
|---|---|---|
| 1 | 쇼츠·릴스·틱톡 규칙 | → 😼 딴짓 (업무모드는 바로 닫기) |
| 2 | 유튜브 영상 종류 (위 표) | 강의·노래 → 📚 / 딴짓 영상 → 😼 / 애매 → 물어봄 |
| 3 | **내가 대답한 것** ("이것도 공부야?") | 한 번 답하면 계속 기억 — 공부든 딴짓이든 |
| 4 | **경로 규칙** (한 사이트 안에서 주소로) | 유튜브 홈 피드·채널·구독 페이지 → 😼 / 유튜브 검색 → ❓ |
| 5 | **내장 목록** (특히 한국 사이트) | VS Code·한글·GitHub·백준·위키독스·`*.ac.kr` → 📚 / 네이버 웹툰·인벤·더쿠·쿠팡·넷플릭스 → 😼 |
| 6 | **공개 사이트 분류 목록 (UT1)** | 게임·SNS·동영상·스포츠·도박·만화·쇼핑·데이팅 사이트 약 12만 개 → 😼 |
| 7 | 제목 키워드 | 강의·파이썬 등 → 📚 |
| 8 | 그 밖 | ❓ 모름 → 30초 넘게 보면 **"이것도 공부·업무야?"** → `응, 기억해` / `이번만` / `아니, 딴짓` |

- **딴짓으로 판정된 창은 무엇이든**(유튜브 딴짓 영상, 넷플릭스, 게임, 유튜브 피드 …) 업무모드에서 5분마다 한 단계씩 반응한다 (간격은 DB의 `block_rule.step_sec`). 브라우저 종류와 상관없다.
- 공개 목록은 처음 켤 때 뒤에서 한 번 받는다 (약 12MB). 새로 받으려면 `python cat_app.py --update-sites`. 내가 대답한 사이트는 목록이 덮어쓰지 않는다.
- 목록 위치: `cat_app.py`의 `FOCUS_APPS`, `FOCUS_HOSTS`, `DISTRACT_HOSTS`, `PATH_RULES`
- 공부로 판정된 창에 20분 있으면 **"어디야? 아직 공부·업무 중이야?"** 하고 확인한다. 3분 안에 대답이 없으면 그때부터 자리 비움으로 센다 (강의를 틀어 놓고 자리를 비운 경우).
- 창 판정: 📚 집중 / 😼 딴짓 / ❓ 모름 / 💤 자리 비움 → 고양이 창의 **📊 오늘 한 일** 버튼으로 판정별로 무엇을(사이트·앱·제목) 몇 분 했는지, "어디야?" 대답과 메모, 최근 채찍·당근 점수를 본다.
- **🧠 배운 것** 버튼: 내가 대답해서 고양이가 기억한 사이트·영상 목록. 잘못 답한 것은 골라서 지우면 다음에 다시 물어본다.

### 👀 20-20-20 눈 쉬기 (모드와 상관없이)
화면을 **20분** 보면 화면을 까맣게 덮고 고양이가 나와 **"창밖 6미터 먼 곳을 바라봐"**를 **20초** 센다.
- 20초 넘게 자리를 비웠으면(입력 없음) 이미 쉰 것으로 보고 20분을 다시 센다.
- `Esc`로 건너뛸 수 있다 (기록되고 점수에 반영). 고양이 오른쪽 클릭 메뉴에서 끄고 켠다.

### 🐱 움직이는 고양이 (앱의 얼굴)
바탕화면 오른쪽 아래(작업 표시줄 위)를 돌아다니는 고양이. 그림 파일 없이 코드로 그린 **손그림 낙서 스타일** (굵은 진회색 선, 흰 몸, 분홍 귀·볼, 점 눈). 무늬는 `cat_sprite.py`의 `SKIN`: `calico`(크림 무늬, 기본) / `white`.

| 조작 | 하는 일 |
|---|---|
| 드래그 | 고양이 옮기기 |
| 클릭 | 쓰다듬기 💕 |
| 더블클릭 | 🐟 간식 주기 |
| 오른쪽 클릭 | 메뉴: 감시/업무모드 · 간식 주기 · 눈 쉬기 켜기/끄기 · 🧪 테스트 모드 켜기/끄기 · 오늘 한 일 · 배운 것 · 고양이 창(설정 패널) · **재우기(끄기)** |

고양이가 하는 모든 일은 고양이가 몸으로 보여 준다: 말하기 = 말풍선 + 화남 · 소리 끄기 = 스피커 위에 앉기 · 기다리게 = 화면을 덮고 두 팔 벌려 막기 · 탭 닫기 = 앞발 휘두르기 · 눈 쉬기 = 화면을 덮고 먼 곳 가리키기. 질문 창도 고양이 옆에 뜬다.

### 🐟 간식과 😺 기분
| | 규칙 |
|---|---|
| 간식 벌기 | 딴짓 없이 **20분** → +1 (딴짓하면 처음부터) · 잘한 날(점수 +10 이상)은 다음 날 보너스 |
| 간식 잃기 | 고양이가 딴짓에 반응할 때마다(쇼츠, 딴짓 단계) -1 |
| 간식 주기 | 더블클릭 → 간식 -1, 포만감 +1 (최대 5) |
| 배고파짐 | 앱이 켜져 있는 동안 **1시간마다** 포만감 -1 |

기분은 **포만감**으로 정해지고, 기분만큼 딴짓 단계 간격이 바뀐다 (간식을 먹이면 그 자리에서 바뀐다).

| 포만감 | 기분 | 딴짓 단계 간격 |
|---|---|---|
| 3~5 | 😺 기분 좋음 | **2배로 확장** (5분 → 10분) |
| 1~2 | 🐱 보통 | 그대로 |
| 0 | 😾 화남 ("간식이 없잖아!") | 절반 |

### 채찍·당근 (하루가 끝나면)
다음 날 처음 켤 때 전날 점수를 매긴다. 평소 = 최근 7일 평균.

| | 조건 | 점수 |
|---|---|---|
| 🥕 | 집중 30분 이상 · 평소보다 더 집중 · 숏폼 0회 · "어디야?" 모두 대답 | +5 · +5 · +3 · +2 |
| 🪓 | 딴짓 30분 이상 · 평소보다 딴짓 20%↑ · 숏폼 1회당 · "어디야?" 무응답 1회당 | -5 · -5 · -2(최대 -10) · -1 |
| 👀 | 눈 쉬기 모두 지킴 / 건너뛴 만큼 | +2 / -1(최대 -3) |
- 고양이는 과정을 표로 보여 주지 않고 말로 예고한다: "또 쇼츠야? 한 번 더 보면 소리 안 들리게 할 거야."
- 앱을 끄면 **이번에 켠 뒤**와 **오늘 전체**의 앱 사용 시간이 따로 나온다.
- 고양이 앱 자기 창(질문 창 등)에 있는 시간은 세지 않는다.
- 감시 모드에서는 할 일을 묻지 않고 기록만 한다.
```powershell
python cat_app.py --report        # 오늘 가장 많이 쓴 앱 TOP 5
python cat_app.py 업무모드 --test  # 🧪 테스트 모드: 모든 간격을 초 단위로 (DB 설정은 그대로)
```

> 한 번에 하나만 실행된다. 이미 켜져 있으면 두 번째 실행은 안내 메시지와 함께 종료된다.

> 🧪 `--test` 간격: 딴짓 단계 10초 · 간식 20초 · 눈 쉬기 30초마다(5초 쉼) · 어디야 40초(무응답 15초) · 배고픔 1분 · 애매한 영상/모르는 창 질문 5초

> 스키마를 올릴 때는 자동으로 DB를 백업한다 (`cat.backup-v{버전}.db`, 최근 2개).


## 구조
| 파일 | 역할 |
|---|---|
| `cat_sprite.py` | 움직이는 고양이 (Canvas로 그림, 자세·애니메이션·마우스 조작) |
| `watch.py` | 창 감지(Windows), 규칙 판정, 세션 집계 — 스파이크에서 검증된 로직 |
| `cat_app.py` | 규칙을 SQLite에서 읽고 기록을 SQLite에 저장하는 앱 본체 |
| `설계/sqlite(db설계도).md` | DB 설계도 (ERD, 설계 이유) |
| `cat-spike/README.md` | 초기 검증(스파이크) 체크리스트 |
| `진행도.md` | 개발 진행 기록 |
